AWAN PK Exchange — PWA-ready demo

اس ZIP میں ویب ایپ کو انسٹال ہونے والی PWA بنانے کے لیے ضروری فائلیں شامل ہیں:
- index.html: ڈیمو ایپ اور عوامی BTC/ETH/DOGE قیمتیں
- manifest.webmanifest: ایپ کا نام، آئیکن اور انسٹال سیٹنگز
- sw.js: بنیادی آف لائن کیش
- icon-192.png اور icon-512.png: ایپ آئیکنز

اہم:
1) یہ ابھی Android APK فائل نہیں ہے۔
2) اسے انسٹال ہونے والی PWA بنانے کے لیے HTTPS والی ویب سائٹ پر اپ لوڈ کرنا ہوگا۔
3) پھر PWABuilder جیسے ٹول میں ویب سائٹ کا URL دے کر Android پیکج بنانے کا مرحلہ کیا جا سکتا ہے۔
4) BTC/ETH/DOGE کی قیمتیں عوامی Binance API سے لینے کی کوشش ہوتی ہے؛ XAUT ڈیمو ہے۔
5) Buy/Sell، Wallet اور History صرف فرضی مشق ہیں۔ حقیقی رقم یا کرپٹو کی خرید و فروخت نہیں ہوتی۔
